# Sample SPRX vsh plugin using PS3DK
You will need:  
* `PS3DEV -> Toolchain binaries`  
* `PS3DK  -> PS3DK Cell style library`  
* `PS3_TOOLCHAIN_ROOT -> For accessing PS3DK's cmake toolchain file`  
  
all defined in your shell.  
  
This project compiles a working PRX module you can attach to the VSH process and safely unload using WebMAN.
